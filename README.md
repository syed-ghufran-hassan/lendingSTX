## DeFi Lending Pool

A decentralized lending protocol on Stacks with dynamic interest rates, collateral management, and liquidation logic.

## Features

    Supply/Borrow: Deposit tokens to earn interest or borrow against collateral

    Dynamic Interest Rates: Rate adjusts based on pool utilization

    Health Factor: Real-time liquidation risk monitoring

    Liquidation: Secure liquidations with bonus incentives

    Price Oracle: Configurable token pricing
